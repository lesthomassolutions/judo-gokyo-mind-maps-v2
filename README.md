# Judo Gokyo Mind Maps V2

Private modernization of the original right-sided educational mind maps.

Phase 1 preserves all original techniques, directional success areas, attack options and intentional loops while updating presentation and usability. The owner confirms the source was verified by their sensei. Left-handed mode and other enhancements are deferred to Phase 2.

- [Confirmed content decisions](docs/planning/CONTENT-DECISIONS.md)
- [Current scope](docs/planning/SCOPE-AND-DESIGN.md)
- [Original inventory](docs/inventory/README.md)

The original repository and public website remain untouched. No deployment without explicit approval.

## Review the current build

Run npm run build:preview to generate Judo-Mind-Maps-Preview.html, then open that file locally in a browser. The standalone copy contains the maps and images; internet is only needed for videos and external links.

See [build instructions and verification limits](docs/PHASE-1-BUILD.md). The source is in web/, with npm start and npm test available when Node is installed.
