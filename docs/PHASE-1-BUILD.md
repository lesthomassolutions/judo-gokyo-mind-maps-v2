# Phase 1 review build

A dependency-free static application in web/ modernizes the original right-sided mind maps. No left-handed control or mirrored content is present.

## Open a review copy

Run npm run build:preview to generate Judo-Mind-Maps-Preview.html, then open it in a current browser. It contains the application, map data and original GIFs in one file; no server or installation is needed. Videos and external resource links still need internet access.

For source development with Node installed, run npm start and open the printed local URL. Run npm test for the preservation checks. The web/ directory is also the static hosting root when deployment is eventually approved. No publication is configured or authorized.

## Preserved

40 technique pages, five original Gokyo groups, original category memberships, 1,211 technique-link placements / 1,151 directed pairs, success regions, Tai-otoshi's self-link, repeated/bilateral placements, 40 illustration/video associations, introduction, credits and original usage terms. Original GIFs are copied unchanged.

The original Ne-waza section is retained as unfinished content. The successful-throw path remains visible without inventing new ground-work maps.

## Implemented presentation behavior

Shared modern page shell; group/category navigation; original directional diagrams with original placement geometry; zoom/scroll and equivalent text links; consistent overview navigation; browser history; original .htm route aliases; updated help; semantic controls and focus styles; native video dialog with Escape/close removing the player; print styling with title/perspective/credits.

## Verification so far

Nine preservation checks passed. Browser observations confirmed the overview and O-soto-gari/Tai-otoshi maps, an intentional Tai-otoshi repeat, attack navigation and Back, successful-throw continuation to the Ne-waza stage, and Escape closing/removing the video iframe while returning focus.

Desktop and 390 × 844 phone screenshots were saved in the local review package. Phone browser checks confirmed the collapsed navigation, map scrolling, Fit map control and text-link alternative. Print rendering remains unverified. Playback of all forty videos, full keyboard/screen-reader acceptance and print output are not claimed as passed. These limits must be resolved before calling Phase 1 acceptance complete or deploying.

The original repository and website have not been changed.
